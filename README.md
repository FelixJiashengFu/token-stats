# @local/token-stats — 真实会话 Token 统计

基于**你自己的真实会话日志**的统计插件，没有任何模拟数据。

## 数据来源（真实数据链路）

- Host 端通过 `sessionQuery` 服务读取全部会话的持久化日志
  （`listSessions` + `readSession`），逐条折叠 `assistant/message` /
  `assistant/attempt` 事件上的 provider usage
  （`inputTokens / outputTokens / cacheReadTokens / cacheWriteTokens /
  reasoningTokens`）。
- 折叠语义与官方 `tokenUsage` 投影一致：同一 turn/step 的重复采样按
  「替换」处理（重试不会重复计数）；分叉会话跳过继承前缀，不重复统计
  父会话用量。Token 总量 = 未缓存输入 + 缓存读 + 缓存写 + 输出
  （推理 token 是输出的子集，单列展示、不重复相加）。
- 模型归因来自每个请求实际的 `request/header` 路由（provider/model）。
- CPU 数据由 Host 进程每 2 秒采样：系统总 CPU 利用率、Harness 进程
  CPU（占整机容量与单核两种口径）、负载、系统/进程内存、运行时间，
  保留最近 6 分钟曲线。
- Host 在 `GET /token-stats/v1/stats` 提供一份 JSON；客户端轮询渲染。
  首次打开会增量索引全部历史会话（界面有进度），之后只重扫有变化的
  活跃会话。

## 界面

- 左侧栏「Token 统计」面板（全局页）：
  - 总 Token（分项）、会话数量（进行中/今日活跃/本月新建）、模型请求数；
  - 估算总成本、本月成本与**月度预算**进度、超支警告、按当前节奏的
    月底预测；
  - Token 消耗**时间线**（7/30/90/180 天/全部，可切换 Token/估算成本）
    与今日分时图；
  - 按模型分布（用量、占比、成本）；
  - **各会话明细表**：标题、模型、创建/最近活动、轮次/消息、请求数、
    Token、占比、估算成本，支持搜索与四种排序；
  - CPU 与系统监测卡（实时曲线）。
- 右侧边栏有一个「Token 统计」页签（窄栏单列版：总 Token、会话数、
  估算成本、预算进度、近 30 天时间线、今日分时、模型分布、用量最高
  会话榜、CPU 实时监测），底部按钮可打开完整面板。有
  dsh-better-sidebar 时注册为它的页签，否则回退原生右侧栏。

## 成本与预算（官方历史价）

没有服务商账单接口，成本仍为估算，但默认计价已改为：Host 折叠每条
用量样本时，按**该请求时刻、该模型在厂商官网公布的官方价格**逐条计价
（`stats-pricing.js`，价格表带出处、抓取日期与生效时段）：

- **DeepSeek**（deepseek-flash / v4-pro）：官方**人民币**价 2026-09-10
  生效新表（flash 峰时段缓存命中 ¥0.04、未命中输入 ¥2、输出 ¥8 每百万，
  谷时段减半；pro 为 ¥0.30/¥9/¥27）；峰时段 = 北京时间周一至周五
  9:00–12:00、14:00–18:00，中国法定节假日除外——按每条请求的实际时刻
  逐条判定峰谷。依据：官方中文定价页（2026-11-02 抓取），英文价表
  2026-09-11、2026-10-20 存档与实时页面一致；新价生效见 2026-09-10
  发布说明。中国厂商今后新增模型同样按人民币官方价（规则在
  `stats-pricing.js` 中按厂商标注币种）。
- **Google**（gemini-3.8-flash $0.75/$0.075/$3.75、3.5-flash-lite
  $0.30/$0.03/$2.50 每百万，美元）：官方定价页（页面明示现行价至
  2026-12-31）。美元金额按加拿大央行官方汇率（2026-11-02：
  USD/CAD 1.3978、CNY/CAD 0.2102）换算为**加元**展示与汇总、与预算比较；
  模型行上 DeepSeek 显示 ¥、Google 显示 CA$。
- **无公开官方价的模型**（meta/muse-*、freellmapi/auto、部分 wb-proxy
  预览模型）：其 token 单独计入「未计价」，成本记 0，**不用编造价格**；
  经代理转售的 wb-proxy/deepseek-v4.1-flash 按底层 DeepSeek 官方价单列
  「代理底层价」，代理加价不计。

界面可切换「自定义单价」模式（旧行为：可编辑单价保存在 localStorage
`token-stats.settings.v1`，不上传）。月度预算与两种模式共用，官方模式
下预算按美元与官方价月成本比较。

## 已知限制

- 金额均为估算，与服务商结算必然有差异：免费额度、阶梯优惠、订阅制
  账号的边际成本、代理加价、Gemini 缓存存储费（按小时计、无数据可算）
  均未建模。deepseek-account 通道若实为订阅制，其边际成本低于按量价。
- 价格表抓取于 2026-11-02；厂商此后调价需更新 `stats-pricing.js`。
- 桌面端若以 Electron `file://` 方式加载界面（而非 Web 地址），相对
  路径 fetch 不可用时面板会显示读取失败；当前 Web 界面不受影响。
- `/token-stats/v1/stats` 与界面同源、无 CORS 头：其他网站读不到，
  但本机任意进程理论上可读取该聚合统计（不含对话内容，仅标题与用量）。
